# 🎲 MONOPOLY PRO 3D (Android Edition)

لعبة مونوبولي احترافية متكاملة (بنك الحظ الاحترافي) للأندرويد، مصممة بأحدث معايير الألعاب الحديثة:
- **النمط الفني (Art Style):** Low Poly / Stylized 3D بألوان مبهجة وظلال ناعمة.
- **خامات محاكاة الواقع (Skeuomorphic Board Design):** لوح كرتوني ملموس بإطار خشبي، بيادق معدنية ذهبية ومعدنية عاكسة (Brass/Chrome Pawns)، ونرد بلاستيكي مصقول عالي اللمعان مع فيزياء رمي 3D.
- **واجهات المستخدم (Juicy Casual UI):** أزرار عريضة ثلاثية الأبعاد بوميض دوري، مؤثرات ارتدادية، وانفجار قطع نقدية (Coin Particles).
- **المزايا الاستراتيجية:** بناء الطوابق (1 إلى 4 طوابق ليمونية) وبرج إيفل الذهبي (الطابق 5)، قطارات السفر السريع، المزادات العلنية بمؤقت 5 ثوانٍ، المقايضة، والسجن بحركة تراجعية مع صوت السارينة.
- **اللغات:** دعم 14 لغة عالمية مع توطين كامل لأسماء المدن (عربية، أوروبية، آسيوية).

## 🚀 كيفية بناء ملف APK:

### الطريقة الأولى: عبر GitHub Actions (تلقائياً بدون تثبيت برامج):
1. ارفع المشروع إلى مستودعك على GitHub.
2. اذهب إلى تبويب **Actions** واضغط على سير العمل **Build MONOPOLY PRO 3D APK**.
3. اضغط على **Run workflow**.
4. عند انتهاء البناء، ستجد ملف `MonopolyPro-3D-APK` متاحاً للتحميل المباشر والتثبيت على هاتفك!

### الطريقة الثانية: عبر Android Studio (محلياً):
1. افتح برنامج **Android Studio**.
2. اختر **Open** وحدد المجلد الجذري للمشروع.
3. انتظر مزامنة Gradle، ثم اضغط على **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
